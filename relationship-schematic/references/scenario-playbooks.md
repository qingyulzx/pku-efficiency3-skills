# 场景深度手册（生成 / 编辑 / 混合材料）

SKILL.md 正文内联了红线与硬 case 速查规则；本文件是展开版，只在需要深挖某一
场景时读。判据本身与速查规则一致：**先看速查定骨架，再按需来这里取细节**。

## 0. 通用硬规则（三场景共用）

1. **引文逐字**：从 Step 2 解析文本复制（只修 PDF 换行），`quote` 字段内绝不
   改写；定位 = 文件 + 页/节/行。没有定位的引文不算证据。
2. **方向不猜**：材料没说就 `direction: "unknown"`（虚线 + `?`）；材料说了就
   按语句语义定 `from`/`to`（"A inhibits B" ⇒ from=A, to=B）。
3. **数值保真**："3.3–10.4%" 原样进 label，带单位；四舍五入、补单位 = 编造。
4. **包含 = 嵌套组框**：`groups` + `contains`，绝不画成边或并列；无交互的并列
   共现用 `parallels`。
5. **判断留痕**：同义词合并、冲突取舍、砍掉的关系都进 `uncertainty`，附双方
   引文——审稿人能复核你的每个决定。

## 1. 生成场景（材料 → 新图）

**判据**：案例给材料（论文 PDF/文本/数据表）要求画机制图、通路链、流程图或
结构包含图。这是默认场景，走 SKILL.md Step 1–7 全链。

- **材料是 PDF**：必须先 parse_sources 再抽取（直接读 PDF 常把换行/表格错读，
  这是旧版实测失败点）；引文带页码定位。
- **材料含数据表**：图例项、配色、标记形状与表列**逐项对应**（分类数目必须
  一致）；数值进 label 逐字保真。数据更新后图同步更新 = 改 model.json 的
  label/成员后重跑渲染-核对链，不是手改图。
- **材料给图面约束**（尺寸/字号/色彩）：进 `canvas_width`、`legend_extra` 等
  模型字段；约束冲突（内容放不下）→ `canvas_expanded` 警告如实带出，绝不裁剪。

**完成标准**：verify exit 0（fail=0）+ 抽查 3 条 `data-evidence-quote` 逐字命中
材料 + 图例覆盖每个画出的关系类型。

## 2. 编辑场景（改已有 SVG）

**判据**：案例给一个 SVG（多半是本技能风格或近似）要求改。先判定改动类型再
动手——这是本题编辑场景的核心决策：

| 改动类型 | 判别 | 处置 |
|-|-|-|
| 局部（改标签/颜色/边类型/标题、删无依赖元素） | 语义结构不变 | `edit_svg.py` + edits JSON（每个 op 带 reason）；`preserved.ok` 证明未动元素逐属性不变；重导出 |
| 结构（加删实体/关系、翻转方向、重组包含） | 语义结构变了 | edit_svg **设计上拒绝**（原地翻箭头 = 画撒谎的箭头）；从 SVG data 属性重建 model.json → 改模型 → 重渲染 → 重核对 |
| 外来 SVG（无 data 属性） | 无法寻址 | 从源材料重建模型重渲染，不手改；记 `change_records` |

**防篡改语义**：改完必须重跑 verify——几何方向检查会抓住任何 data 属性与实际
几何不符的手改（"ARROW POINTS THE WRONG WAY"）。

**完成标准**：局部改 → `preserved.ok = true` + 重导出成功；结构改 → verify
exit 0；`change_records` 讲清改了什么、为什么、没动什么。

## 3. 混合/困难场景

- **多来源**（论文 + 补充材料 + 案例文本）：每条 evidence 带 source id（DOI/
  文件名）；两来源冲突 → 保更具体/更晚出的引文，双方引文 + 冲突说明进
  `uncertainty`。
- **扫描件**：文字极少 → `uncertainty` + OCR 后重跑解析；OCR 不可用 → 只按
  可读部分画 + 在 result.json 声明缺口。
- **要统计图表**（数值轴/误差棒/分布）：超出本技能核心（不做统计计算与方法
  选择）。仍交付能用的部分：实体表、数据→图例映射纪律、可编辑源组织；其余
  字段 null + 原因，status `partial`。
- **密集图**（>40 关系）：拆子图（嵌套 groups）或加宽画布；长边不可避免时
  布局报告如实记录。
- **无契约 case**：用 output-schema.md §3 默认契约兜底。

## 4. 失效模式对照（评分视角的自检）

| 评分视角的失效 | 本技能防线 |
|-|-|
| 抑制画成激活 | 符号语义库（钝端杠=抑制、三角=激活）+ verify `marker_semantics` |
| 上下游颠倒 | from/to 编码语句语义 + verify `marker_geometry`（尖端必须落在语义目标一侧） |
| 包含画成并列 | 嵌套组框 + verify `containment`（组框真包住成员、不误包非成员） |
| 图里出现材料没有的实体/数值 | 无引文关系拒画（error）；实体无引文 warn 如实上报；回读覆盖检查（篡改检测） |
| 图例与数据对不上 | 图例自动从符号库生成 + `legend_coverage` 检查；数值逐字保真 |
| 只交付位图 | SVG 主源（元素 id + data-evidence-*）+ 300dpi PNG + 矢量 PDF + 导出合规检查 |
| 改一个标签整图重画 | edit_svg 源保留编辑 + preserved 证明 |

每一条都是脚本强制的检查项，不是自律承诺——这是「画得对」可以被独立核验的
全部机制。
