# 案例研究：一张能进论文的图差在哪

> 对应题目：科研数据图表生成与编辑（challenge-1bd90d8a）
> demo 产物：本目录 [demo/](./demo/)（真实论文 arXiv:1706.03762 Table 2 数据 → SVG/PNG + glyphs.json 映射表 + 回读校验报告）

## 1. 人类经验是什么

给期刊画过图的人有一份刻在肌肉记忆里的清单：

- **期刊规范是硬约束**：Nature 双栏图宽 89mm、图内字号 5-7pt、色觉无障碍色板（Okabe-Ito）、文字绝不转曲（编辑部要求可编辑——"Do not outline text" 是 Nature 官方 author guidelines 原文）；IEEE/PLOS 各有各的数
- **柱高/点位必须从源数据逐个可追**：每根柱对应源表哪个数、误差线是 SEM 还是 SD，交图前自己对着原始表核一遍
- **图例、单位、色阶与数据一一对应**——错一个就是审稿意见

基础 Agent 的典型失败：图看起来像样，但柱高和源数据对不上、字号不合规、文字转曲无法编辑。

## 2. Skill 怎么编码这段经验

- **期刊 profiles**（references/styles/nature|ieee|plos|default.json）：数值取自各刊官方 author guidelines 逐字摘录（带 URL 与核对日期），字号范围由校验器自动检查
- **glyphs.json 显式映射**（chartgen.py 产出）：每根柱/点/色块 → 源数值 → 来源（哪张表哪行哪列）→ SVG 像素几何
- **回读校验**（verify_svg.py）：从渲染出的 SVG **实测**矩形高度/圆点坐标/误差线长度/扇区角度，用 SVG 自身刻度**独立重建**像素→数值标定（不信任渲染器记录），反算数值与源数据比对（公差 = 轴跨度 0.5%）
- **可编辑性**：SVG 文字保持 `<text>`（校验器检查防转曲）、PDF Type 42

## 3. 增益怎么验证（现场可演示）

- **篡改检测**：把渲染好的图中数值 28.4 偷改成 33.4 → 校验器 exit 1，精确报出被篡改的 glyph——基础 Agent 只产位图，没有映射表就**不可能**做这种核验
- **回归实测**（demo 数据）：15 根柱回读误差 ≤1e-8、误差线 0.1→0.1 精确、饼图 4 扇区角度误差 0.0、热图 12 单元格颜色回读通过
- **Y 轴标定独立性**：校验器不读渲染器自述的坐标，而是从 SVG 自身刻度重建——这是「验证器不信任被验证方」的设计原则
