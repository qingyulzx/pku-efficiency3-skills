# 抽取手册（Agent 判断规则）

脚本负责解析、渲染、校验；**部件识别、连接方向、阶段划分这些科学判断由你（Agent）做**。
本手册是判断规则，照着走能把「画得像但不对」的那类错误堵在源头。

## 1. 部件识别（apparatus）

从材料（装置清单 / 装配说明 / 方法段落）里找「有边界的功能单元」。判据：
- 被名词化指称且参与流程（气瓶、泵、反应器、传感器、电源…）；
- 同类多台必须分开建（4 个磁控溅射靶 = 4 个 component），除非材料明确
  说它们作为一个单元工作（「四通道质量流量计组件」= 1 个）；
- 只在背景/展望里提到、不参与当前流程的设备：进 extraction_index，
  `status: "omitted"` + reason，**不画**。

规格（温度/压力/流速/尺寸/型号）：材料给了就进 `specs`（key/value 逐字取数值）；
没给就 `certainty: "unspecified_spec"`。**永远不补造数值，不把别的部件的数值
挪用过来。**

## 2. 连接判断（apparatus）

- 只建材料支撑的连接：逐字写出（A 与 B 相连 / 气体从 A 流入 B）→ quoted；
  只写了上下游顺序、连接关系是推断 → `certainty: "inferred"`；
  两者皆无 → 不建连接，部件进未连线区。
- 方向对着动词确认：中文「A 经 B 进入 C」：A→B、B→C；英文 "effluent from A
  is directed to B"：A→B。回流/循环（"recycled back", "返回", "循环")：
  正常建边（布局会自动走下方廊道）。
- `medium`（介质）和 `kind`（material/signal/energy）：介质名从材料取
  （N2、Ar、样品液、冷却水…）；信号线（数据采集、控温反馈）用 kind=signal，
  别把电缆画成气管。

## 3. 阶段划分（route）

- 阶段 = 材料里被明确区分开的任务块（章节、编号步骤、时间先后）。判断依据：
  显式编号（"Step 1/2/3"）、章节结构（2.1 合成 / 2.2 表征）、连接词
  （"随后""after that""在此基础上"）。
- 主序列 vs 并行支路：材料说「同时/分别」→ 并行（两节点同列）；
  默认主序列。
- 决策点：材料写了条件分支（"若…则…否则…"、"if … otherwise …"）→
  `kind: "decision"` 节点，出边带 `condition`。
- 循环/迭代（"重复直至…"、"不达标则返回配方优化"）→ 回边，`kind: "loop"`
  + `route: "below"`。
- `step_no` 必须与材料编号逐条一致；材料没编号就不编造，用材料原文顺序。
- 阶段目标/输入/输出/里程碑：材料写了才填，并附 quote；没写的字段留空。

## 4. certainty 与不确定性的诚实标注

| 情形 | 处理 |
|-|-|
| 规格未给 | certainty=unspecified_spec，图上自动「△ 规格未提供·示意」 |
| 连接靠推断 | certainty=inferred，灰虚线 |
| 步骤顺序有歧义（两种读法都通） | 选更常见的一种，在 result.json 的 uncertainty 里写明歧义原文与选择理由 |
| 材料自相矛盾 | 以更具体/更新的表述为准，uncertainty 里记录矛盾位置 |
| 部件数量不确定（"若干传感器"） | 画一个并标「数量未明示」于 uncertainty，不画 N 个假的 |

## 5. extraction_index 纪律

每读一遍材料，把**所有**候选实体/步骤登记进 extraction_index（mention + quote），
然后逐条决定 mapped_id 或 omitted+reason。这一步偷懒会让覆盖检查形同虚设——
覆盖检查的上限就是索引的完整度。

## 6. PDF 材料处理

- 用容器的 pdf-text-tool 取文本；扫描件/图片页用 ocr-tool；
  两者都失败 → 该页内容进 uncertainty，注明页码，不猜内容。
- PDF 里的图（装置照片/已有示意图）可用 pdf-render-tool 渲染查看辅助理解，
  但**引用文本必须来自文字层/OCR 结果**，并记录页码。
- 公式编号、表格数值引用时记录页码+表号。

## 7. 常见坑

- 中文材料「预热炉」≠「管式炉」：label 保留原文，type 可以同为 furnace。
- 英文 "line" 既指管路也指产品线：看上下文，装置语境一律是管路。
- 「经检测器后排空」：排空不是部件，是流向终点；终点画箭头指向图外即可
  （或建一个 "vent/end" 类型的 other 节点并标 omitted 理由之外的来源）。
- 别把厂家型号当介质/条件：型号进 specs，不进 medium。
